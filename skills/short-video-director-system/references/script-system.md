## 选型原则

- 需要用户学会判断或方法：知识。
- 需要用户认同一个立场：观点。
- 需要用户通过人物经历产生信任：故事。
- 需要用户观看一件事如何发生：晒过程。

同一素材可以有多个类型，但一条视频只选一个主类型。

## 文案问题分诊与语言修订

先区分定位/选题、事实素材、结构、语言、现场表达和产品承接缺口；只修最上游的主问题，不能用润色掩盖没有素材、证据或产品价值。

需要快速理解时，把抽象判断落成“谁在什么情境做了什么、什么东西出现在哪里、发生了什么变化”，再加入经核验的时间、地点、物件、数量和角色。具体不自动等于真实，抽象也不自动无效。

故事尖峰从完整时间线中的真实临界点选择，保留前因、后果和因果；冲突不是必需品，不拼接事件或补编敌人、伤害和第三方态度。押韵、排比、顶真和长短句只调度记忆、逻辑与情绪，语义和口语自然优先。

结构先写受众当前认知与目标理解、感受或行动，为每段标注“新增什么—为何现在出现—下一步需要什么”。AIDA、PAS、QUEST、BAB 等只作候选顺序，不是统一公式。

## 粗纲、清单/发展与材料扩充

先搭粗纲，再分轮细化：第一轮写中心承诺、目标受众、结论和必要事实；第二轮检查结构与材料缺口；第三轮核事实、授权和因果；之后才处理语言、镜头、声音与节奏。AI 可做候选大纲和缺口检查，不能越过人工核验直接补编成稿。

把观点、人、物、事分别按两种主结构组织：

- 清单式：多个并列或有次序的材料共同形成理解；每项必须增加独有价值并服务同一中心承诺。
- 发展式：每个节点都能写成 `阶段判断 → 新问题/证据 → 行动 → 结果 → 修正`；没有真实因果、时间、条件、反证或判断修正时，退回清单式。

发展式不是更高级的外观。不得虚构粉丝消息、发现、客户/家人陈述、阻碍、敌人、关系或结果制造反转；情绪、表演与氛围不能替代事实和因果。

材料不足时可组合三种动作：向下细分为不同分项/步骤；向上汇总到仍服务同一用户目标的上位主题；向内折叠到可观察的部件、动作、感官、条件和变化。若仍没有独有、相关、真实且可理解的材料，就缩小承诺或换题，不套固定信息点数、秒数和记忆时长。

## 知识型脚本

### 解决难题/放大危机

`具体场景难题或危机 → 一句话解决方向 → 具体步骤 → 素材库/自身经验 → 结果`

危机必须真实、具体且与人群有关，不制造虚假恐惧。

### 案例引入

`热点/成功/失败/名人/影视案例 → 描述事件 → 提取知识点 → 用户应用方法 → 操作步骤 → 具体例子`

案例用于降低理解门槛，不替代方法本身。

### 推荐建议

`美好愿景/明确人群/好奇问题 → 三个筛选标准 → 推荐对象 → 推荐理由 → 排列顺序 → 适用边界`

可推荐书、工具、产品、地点、博主、网站、品牌和妙招。课程中的排列技巧包括把门槛低的内容放两边、熟悉内容放中间，目的是制造获得感；执行时按实际理解成本调整。

### 揭秘避坑

`揭秘事件 → 行业乱象/机制/骗局 → 获利链路、生产方式或行业标准 → 如何识别 → 如何避免 → 正确做法 → 正向呼吁`

必须区分已验证事实和推测，不编造内幕。

### 知识型自检

- 信息多：是否提供判断、方法、步骤、案例或新信息？
- 效果快：用户是否能较快理解或应用？
- 料够猛：是否有具体事实、参数、案例、反差或机制？
- 反馈短：结果能否在合理周期内被感知？
- 是否避免专业词堆砌、反馈周期过长、排列混乱和对象模糊？

## 观点型脚本

### 人群观点

`写作对象 → 人物关系 → 冲突事件 → 选题 → 开篇张力 → 明确立场 → 至少三个论据 → 正反案例 → 结论`

写作对象可来自家庭、工作或社会关系。开篇张力可使用美好愿景、负面后果、制造对立、颠覆认知或寻找责任对象。

### 行业观点

`行业对象 → 产品/从业者/消费者 → 误解或现象 → 批判/支持/建议 → 立场 → 至少三个论据 → 案例 → 结论`

课程注明行业观点通常不需要额外开篇优化，直接进入误解或判断即可；仍需确保非业内观众能理解。

### 论据角度

- 权衡利弊：这么做得到什么，不这么做失去什么。
- 无奈之举：解释当事人的现实约束。
- 不同视角：当事人与旁观者如何看同一事件。
- 人物评价：评价行为、品行或判断，而非无事实的人身羞辱。
- 倒打一耙：指出责任转移或情绪化归因。
- 维度升级：从历史、未来或社会影响重新审视。
- 正反案例：至少用具体案例承载抽象判断。

### 观点型自检

- 写作对象明确吗？
- 立场是否稳定且能被一句话复述？
- 是否替对象想做的事提供了理由，或解释其不想做/没做到的现实？
- 是否至少有三个互不重复的论据？
- 是否有具体案例或事实，而非只输出情绪？
- 是否把相关性误写成因果，或为冲突而故意歪曲事实？

## 故事型脚本

### 通用结构

`反差/异常开篇 → 人物背景与目标 → 一轮困境 → 一轮转机 → 二轮困境 → 二轮转机 → 结果 → 感悟`

不必机械使用两轮；短故事可只保留一轮，但必须有行动和变化。

### 开篇方式

- 强弱对比：负债到高收入、普通身份到突出成就。
- 痛苦桥段：父母阻碍、离婚、朋友背叛、同行欺压。
- 好奇假设：“如果让我回到十年前”。
- 身份/行为反差：某身份做出不符合固有认知的行为。
- 场景/物品反差：某场景出现不该出现的物品。
- 异常反应：面对常见事件做出反常选择。

### 困境库

一轮困境：

- 盲目自信；
- 家门不幸；
- 天灾人祸。

二轮困境：

- 恶霸欺压；
- 过河拆桥；
- 至亲背叛；
- 抢权干涉。

### 转机库

一轮转机：

- 通关密码；
- 至亲寄托；
- 天赋异禀；
- 意外之喜。

二轮转机：

- 因祸得福；
- 贵人相助；
- 破釜沉舟。

“贵人相助”要说明双方关系与具体帮助，不能凭空出现。写自己人设时，可呈现自己曾经先帮助对方的事实。

### 故事母题

- 小有成就或成功案例；
- 平凡英雄；
- 苦难经历；
- 重走成功路；
- 弥补遗憾；
- 跨文化事实展示（课程来源中的“扬我国威”母题经安全改写）；
- 帮助弱者；
- 极限挑战；
- 追根溯源；
- 超级访问。

以上名称只是选型入口，不是完整模板。执行平凡英雄、苦难经历、重走成功路、弥补遗憾、帮助弱者、极限测评/手艺挑战、追根溯源、超级访问或跨文化事实展示时，继续读取 `story-mother-templates.md`；其中也包含口述转写、经典桥段重排、画面感和力量感。

### 故事型自检

- 人物、时间、场景和事件具体吗？
- 有明确目标、冲突、行动、转机和结果吗？
- 有能被画面呈现的经典桥段吗？
- 转机是否由行动、信息或关系推动，而非作者强行安排？
- 感悟是否来自故事结果，而非空降鸡汤？
- 苦难是否以已消化的视角讲述，避免只靠哭诉换同情？
- 帮助弱者是否尊重隐私、界限与体面，不摆拍、不炫耀？

## 晒过程脚本

### 可晒内容

- 产品从筹备、生产、成交到售后的过程；
- 对比、极限或化验测评；
- 金钱、时间、地点限制下的任务挑战；
- 新奇体验、奇葩规则或角色互换；
- 手艺极限、追根溯源或访问过程。

### 火车节模型

课程原词为“晒过程—火车节模型”。按导图流程执行：

`确认晒什么 → 起因加钩子 → 关键步骤经过 → 展现专业点 → 补充事件细节/困难意外 → 关键步骤结果 → 结果展示`

可理解为：

- 火车头：起因、任务和期待钩子。
- 车身：关键过程、专业手法、困难和变化。
- 结尾：结果、前后对比和事件闭环。

### 期待感钩子

当前导图记录九个技巧：

1. 送温暖：帮助弱势、送礼物、买下对方商品。
2. 金钱：花大钱、花小钱办大事、赚钱、省钱、薅羊毛。
3. 对抗：打赌、吵架、被阻止、冲突或意外。
4. 盲盒：结果未知，抽到什么就做什么，能否成功。
5. 验证/揭秘：辨真假、挑战权威、验成分、验价格、破传言。
6. 荷尔蒙：颜值、身材、搭讪、变装、跳舞等吸引力。
7. 意外：撞、跑、坏、碎、丢、突然发现等变化。
8. 惊喜：礼物、求婚、生日、车、房等超预期结果。
9. 整蛊：整蛊玩具、蛋糕拍脸、假装不知情、扮猪吃老虎。

部分课程版本可能把前六项称为“六个核心钩子”；当前导图明确写的是“建立期待感 9 个技巧”。需要引用课程原话时说明版本差异。

课程建议起因必须有钩子，最好组合两个以上；组合时仍要确保真实自然，不能为了钩子摆拍欺骗。

### 晒过程自检

- 一开始是否知道要完成什么？
- 是否有至少一个真实期待钩子？
- 是否保留了关键步骤，而非流水账？
- 是否出现手法、技巧、原料、判断或专业细节？
- 是否有困难、意外、对抗或变化？
- 结果是否清晰可见并兑现开头？
- 两个以上钩子是否互相增强，而非彼此抢戏？

## 通用脚本自检

### 脚本层

- 是否先分清定位/选题、事实、结构、语言、表达或承接缺口？
- 抽象判断是否有必要的可观察动作、场景与经核验细节？
- 每段是否推进目标受众的理解—情绪—行动路径，而不是为了套模板存在？

- 中心承诺只有一个。
- 开篇在短时间内说明“与谁有关、为什么要看”。
- 每一段都推进原因、证据、步骤、冲突或结果。
- 删除重复、正确的废话和无事实支撑的夸张。
- 结尾扣题，可使用总结、引导、号召或金句。

### 发布前

- 结构完整，有中心思想。
- 语言逻辑清楚，画面流畅自然。
- 爆点前置。
- 知识：保留难题、判断、方法、步骤、案例。
- 观点：保留观点、论据和例子。
- 晒过程：保留关键步骤和钩子。
- 故事：保留经典桥段、冲突、行动、转机和结果。
