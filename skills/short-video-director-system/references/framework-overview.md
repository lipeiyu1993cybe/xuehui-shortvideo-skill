## 一句话模型

这是一套从内容价值、注意力、表达结构、现场采集、后期重构到商业转化的短视频编导系统：

`定位 → 选题 → 脚本 → 自然流提问 → 拍摄 → 无稿剪辑 → 精剪包装 → 成交/分发 → 观看/互动/关注/留存 → 经营复盘`

任何环节都受上游约束：

- 定位决定对谁说、解决什么问题。
- 选题决定观众为什么点开。
- 脚本决定内容必须提供哪些信息。
- 自然流提问负责把这些信息从 IP 口中问出来。
- 追问补齐脚本缺口，切走控制节奏。
- 剪辑从原始回答中重建脚本。
- 成交理由决定商业内容如何自然进入。
- 平台规则是发布与风险边界，不是内容价值本身。
- 数据复盘分开观看、互动、关注、留存与业务结果，并与同口径历史基线比较；公开评论不能代表完整受众。

## 八个课程板块

### 1. 内容定位

- 目标人群与用户思维。
- 三有原则：有用、有趣、有共鸣。
- 四种内容：知识、晒过程、观点、故事。
- 变现内容策略：多维、原声、高频。
  - 多维：知识体现专业，过程体现实力/手艺/质量，观点体现支持或批判，故事使用自己的真实经历。
  - 原声：通过置景、灯光、服饰和真实环境强化 IP 识别，不用包装替代内容证据。
  - 高频：围绕稳定人群和内容支柱持续输出，并用数据复盘调整。
- 素材库：选题、开篇、金句、呈现和结构；同行业找选题、跨行业找呈现，并用客观性、有效性、可用性三筛。

### 2. 自然流拍摄剪辑技巧

- 六个现场快速选题切口：头牌、弱势、颠覆、内幕、对立、推荐。
- 追问与切走。
- 三类自然流切点：亲密关系、负面假设、制造对立。
- 场域搭建、拍摄禁忌、镜头脱敏、表现力和拍摄阶段。

### 3. 无稿剪辑思维

- 从全部素材中提取唯一中心思想。
- 判断知识、观点、故事或晒过程。
- 按内容方向保留片段，先归纳再合并。
- 重建开篇与结尾，发布前检查结构与逻辑。

### 4. 基础剪辑思路

- 删除废镜头和重复镜头。
- 字幕、花字、重点缩放、特效、音频和画中画。
- 识别 IP 情绪、表现力、关键信息和逻辑词。
- 检查声音、清晰度、构图与缺镜头。

### 5. 剪辑素材库

- 文字特效、画面特效、音乐和音效。
- 使用抖音收藏夹、剪映收藏夹和电脑文件夹积累。

### 6. 拆片

- 排除无商业属性内容与纯营销号。
- 账号层记录名称、粉丝、行业、人设、内容配比、发布频率、发布时间、昵称和简介。
- 单条视频层记录点赞、评论、主题/IP、爆款元素、剪辑特效、选题和类型、写作对象、脚本结构、拍摄呈现和备注。
- 从数据事实形成竞争性假设，再提炼可控变量做小规模验证。

### 7. 实体商家成交理由

- 从产品、店铺、人三个维度组合内容。
- 十五个理由：效果、服务、老板、生意、质量、案例、选择、好评、面子、特色、专业、颜值、规模、性价比、便利。
- 至少组合两个维度，降低硬营销感。

### 8. 抖音规则课程模型

- 标签：作品、个人喜好、账号。
- 赛马：完播与互动，商品侧点击与转化。
- 铁粉：先由高关联用户反馈影响后续扩散。
- 审核：机器与人工审核、关键词与用户反馈。

平台机制会变化；需要实时判断时核查最新官方资料。

## 上下游关系

### 选题与脚本

爆款选题是脚本的中心承诺，脚本是承诺的展开与证明。标题承诺“避开三个坑”，正文必须给出三个具体坑、识别方法和替代做法。

开篇按“目标受众相关性 → 真实新鲜性 → 相邻扩展”分轮修订；文字、画面、主体、环境、物件、声音和风格共同承担识别任务。开放式悬念必须与目标人群相关并由正文及时兑现，不能以无关流量、虚构危险或隐藏答案代替价值。

### 脚本与自然流

自然流不等于无结构。把脚本字段改成问题：原因、案例、证据、方法、步骤、结果、结论。现场缺哪个字段就追问哪个字段。

### 自然流与剪辑

追问是在现场补素材，切走是在现场做第一次剪辑。后期只重排和压缩已经采到的有效信息；缺关键字段时只能补拍或明确缺口。

### 选题与成交

成交理由不是结尾硬塞广告。产品、店铺或人的成交优势应成为选题事实、过程证据或故事转机的一部分。

## 三种内容目标

- 流量：优先清晰人群、强爆点、理解门槛低和快速反馈。
- 人设：优先真实经历、判断、行动、原则与稳定表达风格。
- 成交：优先真实需求、可信证据、具体场景和购买理由。

一条内容只能有一个首要目标，可以兼顾另外两个，但不能三者平均用力。

## 四种内容类型

- 知识：用户看完能判断、能操作或能避坑。
- 观点：用户获得立场、理由或情绪表达。
- 故事：用户通过人物经历产生情绪与信任。
- 晒过程：用户通过连续变化、专业细节和结果获得期待满足。

## 标准项目流程

1. 明确业务、IP、人群、目标和事实素材。
2. 选择一个五维需求作为内容价值。
3. 选择 1 个主爆款元素，最多再加 1 个辅助元素。
4. 判断四种内容类型并写一句话承诺。
5. 搭建脚本字段，不急着写逐字稿。
6. 将字段改写成自然流问题，标出追问和切走条件。
7. 设计场景、交流对象、内心视像、镜头和设备。
8. 拍摄后提取中心思想，归纳合并素材。
9. 重建开篇、正文和结尾，进行精剪包装。
10. 检查成交理由、平台风险与数据指标。
11. 发布后分层记录观看、互动、关注、留存、对话、线索和成交；只使用聚合、匿名、最小必要数据。
12. 用拆片表记录样本、反例、竞争性解释和下一轮单变量测试；账号停滞时分开验证表达方式与价值供给。

## 最小输入与标准输出

### 最小输入

- 行业或产品；
- IP 身份和可信经历；
- 目标人群；
- 本条目标；
- 一个真实事实、案例、问题或可拍过程。

### 标准输出

- 一句话定位与目标人群；
- 选题矩阵及推荐选题；
- 脚本类型和结构；
- 自然流主问题、追问和切走点；
- 拍摄场景及表现力提示；
- 剪辑结构和包装点；
- 成交植入与发布自检。
