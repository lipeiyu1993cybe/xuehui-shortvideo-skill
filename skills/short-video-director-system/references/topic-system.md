## 正确顺序

先选择五个维度之一确定内容价值，再组合八大爆款元素制造注意力。

`目标人群 + 具体对象/场景 + 五维价值 + 1~2 个爆款元素 + 可兑现结果`

不要先写夸张标题再寻找内容。若脚本无法兑现结果，缩小或改写选题。

灵感来自外部素材时，先用客观性、有效性、可用性三筛过滤：同行业提炼人群需求与选题，跨行业只迁移呈现机制。需要完整入库字段和迁移流程时读取 `content-library-system.md`。

## 五个选题维度

### 1. 追求更好

用户已有解决方案，但想获得更好的效果、标准、体验或身份。

常见结构：`当前状态 → 更高标准 → 差距 → 升级方法 → 更好结果`

### 2. 解决难题

用户在具体场景中被问题卡住，需要明确答案和步骤。

常见结构：`具体难题 → 原因 → 解决方法 → 操作步骤 → 效果`

### 3. 降低成本

降低金钱、时间、精力、学习、试错或关系成本，同时说明必要代价。

常见结构：`原成本 → 替代方案 → 执行方法 → 节省结果 → 适用边界`

### 4. 避免踩坑

帮助用户识别错误、套路、损失和风险。

常见结构：`错误做法 → 损失 → 背后机制 → 判断标准 → 正确做法`

### 5. 丰富谈资

提供反常识、故事、信息差、身份与社交货币，让用户愿意评论和转发。

常见结构：`反常信息 → 细节/案例 → 证据 → 认知结论`

## 八大爆款元素

### 1. 荷尔蒙

在本课程的选题语境中，指能引发本能吸引和即时愉悦的内容线索，课程口语化地概括为“让人产生多巴胺”。黑丝、美女、大长腿、腹肌是典型例子；也包括吸引力、亲密关系、身材、魅力、搭讪和变装等。底层是吸引投射、繁衍与被认可的本能。这里的“荷尔蒙”是内容选题标签，不是医学或神经科学定义。

### 2. 头牌

名人、名企、名校、名牌、最贵、最好评、生意最好、影视作品出现过的对象。底层是权威、地位和社会认同。

### 3. 怀旧

童年、旧年代、古代或具体朝代。底层是共同记忆和身份连续性。

### 4. 奇葩

外行不知道、反常脑回路、黑心操作和异常行为。底层是信息差与猎奇。

### 5. 最差

最难吃、最难用、最丑、最没面子、差评最多、贬值最快、低价极端产品。底层是负面偏好与损失规避。

### 6. 反差

反向操作、身份、古今、中外、男女、南北、品牌、贫富之间的差异。底层是预期违背与认知冲突。

### 7. 人群

亿万富豪、第一次体验者、爱挑刺者、星座/人格、宝妈、学生、上班族和弱势群体。底层是自我投射与群体身份。

### 8. 成本

便宜又有面子、十分之一金钱/时间、花钱办事、占便宜和偷懒。底层是资源优化与捷径偏好。

## 组合方法

### 一主一辅

选择一个主元素负责核心冲突，最多增加一个辅助元素强化人群或结果。堆叠过多会使承诺失焦。

示例：

- 追求更好 + 头牌：头部品牌为什么坚持某个标准？
- 解决难题 + 人群：有孩子的家庭如何解决某个具体问题？
- 降低成本 + 反差：十分之一预算为什么能得到更好效果？
- 避免踩坑 + 最差：最容易后悔的三个选择是什么？
- 丰富谈资 + 怀旧：十年前流行的做法为何消失？

### 选题矩阵

对同一个真实对象分别生成五个维度，再为每个维度组合 1~2 个爆款元素。先发最能被事实和素材支撑的选题，不选择最夸张但无法兑现的选题。

### 选题不是标题

选题包含：人群、对象、冲突、价值和结果。标题只是选题的语言外壳。标题更换后，如果脚本字段不变，通常不算真正换了选题。

## 自然流六个快速切口

这组切口用于现场快速生成问题，与八大爆款元素不是同一套数量口径。

### 1. 头牌

借势名人、名企、名校、名牌；负面或争议通常比单纯夸赞更有张力。

### 2. 弱势

找行业中的弱势群体，询问如何满足他们的具体需求。

### 3. 颠覆

列出行业常识，再询问是否存在相反结论或反常案例。

### 4. 内幕

从不守规矩、见不得光、欺骗、避坑、套路和利益链路切入。

### 5. 对立

制造性别、地域、关系、阶级、内外行或头牌之间的比较。

### 6. 推荐

围绕书单、工具、品牌、妙招、博主、地点、产品和网站，追问筛选标准与推荐理由。

## 选题校验

每个候选选题至少回答：

1. 明确说给谁听吗？
2. 属于五个维度中的哪一个？
3. 主爆款元素是什么？
4. 具体冲突或信息差是什么？
5. 结果是否能由真实素材证明？
6. 应使用知识、观点、故事还是晒过程？
7. 观众在前几秒能理解为什么与自己有关吗？
8. 该选题能否自然延伸到流量、人设或成交目标？

没有明确价值维度的内容容易空洞；没有爆款元素的内容容易正确但无人点击；没有事实支撑的内容容易成为标题党。
