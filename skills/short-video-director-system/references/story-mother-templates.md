# 故事母题执行模板

## 总原则

故事母题是提取真实素材的结构，不要求现实按模板发生。

- 一条内容只选一个主母题。
- 先确认人物、时间、场景、行动、结果和证据。
- 不为冲突、反转或感动编造事实。
- 涉及隐私、创伤、弱者、健康、未成年人和敏感关系时，先取得知情同意，必要时匿名。
- 感悟来自事件结果，不替当事人定义感受。

## 平凡英雄

适用素材：

- 自己遇到倒霉事或突发事件；
- 自己被欺负或冒犯；
- 看到他人被欺负；
- 自己犯错并需要补救。

结构：

`具体冲突 → 当下选择 → 英雄时刻的行动 → 承担代价或解决问题 → 结果 → 价值判断`

英雄时刻可以是敢做敢当、随手帮助、坚守原则、仗义扶弱、积极面对或清楚表达边界。重点写“做了什么、为什么、承担了什么”，不要持续抱怨、摆拍或包装救世主人设。

## 苦难经历

结构：

`愿意公开的缺陷或差异 → 形成原因与处境 → 具体困苦 → 应对与变化 → 今天的理解 → 感悟`

结尾可以鼓励相似处境的人，也可以呈现已经消化后的释怀。不要强迫公开创伤、追拍崩溃、替第三方诊断，或把身体和心理差异猎奇化。

## 重走成功路

选择两到三个真实时间阶段，每段使用：

`时间锚点 → 当下艰辛 → 当时愿望 → 采取的行动 → 发生的变化`

艰辛可从身体、心理、环境提取；愿望可从物质、社会角色、情感关系提取。完整结构以当下结果和回忆录式或感悟式结尾收束。

每段必须有行动。成就和数字要核验，不神化结果，不删掉关键帮助、运气和环境条件。

## 弥补遗憾

遗憾可来自人、事或物。

`遗憾是什么 → 为什么留下 → 为什么现在弥补 → 弥补过程 → 结果 → 感悟`

结果不必圆满。涉及旧关系、重逢或旧影像时取得同意；不逼迫和解，不为镜头重演伤害。

## 帮助弱者及后续

首次故事：

`异常行为或冲突 → 当下困境 → 背后故事与主动性 → 体面帮助方案 → 当事人选择 → 结果 → 感悟`

后续：

`真实重逢 → 经授权回顾旧片段 → 当下现状 → 仍存在的问题或变化 → 未来愿望`

帮助要力所能及、支持自食其力、尊重隐私和拒绝权，不过度介入。帮助可遇不可求，不为内容寻找弱者，不摆拍，不用资助换配合。

## 产品极限测评

`测评对象 → 测评目的 → 测评方向 → 初始状态与标准 → 过程与变化 → 结果 → 边界`

方向包括对比、极端环境、极端方法、成分、效果、耐用和安全测评。开始前说明验证目标；记录条件、变量、样本、误差和全过程。

要实事求是，区分一次测试与普遍结论。食品、药品、医疗、电气、消防等使用适用标准和专业机构；不做危险实验，不伪造失败或恶意破坏。

## 手艺极限挑战

可从实施对象难度或操作工具难度设计：

`精彩片段或难点开篇 → 任务与限制 → 清晰步骤 → 难点细节 → 真实失败与应对 → 关键变化 → 结果与前后对比`

失败必须真实。工具变化要解释特性和处理措施，不制造安全风险。

## 追根溯源

### 原料或工艺

`去产地或现场的原因 → 原料/产品介绍 → 过程 → 质量证据 → 结果 → 品质与工艺结论`

观察质量把控、地理环境、种养方式、工厂规模、设备和技术工艺，但不把规模与传统自动等同于质量。

### 传统文化

`对象与历史位置 → 探寻原因 → 古法或制作过程 → 难度与传承条件 → 成果 → 保护、传承或创新问题`

核验历史、产地、非遗、工艺和品质说法；取得场地与人物许可；尊重文化主体。

## 超级访问

### 商业访问

`嘉宾与成果 → 从业发心/机缘 → 阶段目标 → 最大挑战 → 破局方法 → 创新或成果 → 经验理念 → 前景规划`

### 大师访问

`个人成长 → 技法起源与学习 → 创作和灵感 → 社会价值 → 创新传承 → 未来判断 → 给年轻人的建议`

追问“哪些人做了什么”以还原因果链。可以改变角色、情景、时间和观点提出假设问题。敏感话题只在必要且嘉宾同意时问；不突袭隐私、不诱导指控、不用剪辑改变原意。

## 跨文化事实展示

这是对课程“扬我国威”母题的安全改写：

`可验证的产品、工艺或文化事实 → 自愿参与者 → 说明体验方式 → 记录真实初始认知 → 证据与体验过程 → 参与者自由表达 → 多方视角与边界 → 结论`

- 领先、独有、历史和效果说法必须有证据。
- 参与者不限定国籍，并事先同意用途和公开范围。
- 不预设他人无知、偏见或最终会被折服。
- 不诱导台词，不用翻译、字幕或剪辑夸大态度。
- 允许质疑和不同意见；目标是理解与验证，不是羞辱。

## 母题转自然流问题

把母题字段逐一改成开放问题，再按“原因 → 细节 → 证据 → 行动 → 结果 → 感悟”追问。一个问题只采一个字段；回答形成结论或开始重复时切走。通用规则见 `natural-flow-shooting.md`。

### 帮助弱者

1. 最先看见了什么异常行为或事件？具体场景是什么？
2. 对方眼下真正卡住什么？这是对方表达还是你的判断？
3. 对方已经主动做了什么，有哪些能力和选择？
4. 考虑过哪些帮助方式？为什么这一种更体面、不过度？
5. 拍摄、公开和帮助方案是否由对方知情、自愿选择？哪些不能公开？
6. 双方具体做了什么？中间有什么变化或拒绝？
7. 结果如何，还有什么没有解决？
8. 后续是否自愿？今天的现状和愿望是什么？

不要预设对方“可怜”或理应感激；出现拒绝、不适或撤回同意时停止。

### 追根溯源

1. 为什么去现场，要验证哪一个具体说法？
2. 对象是什么，来源、历史和行业位置有什么可核证据？
3. 哪个环节影响质量、难度或传承，判断标准是什么？
4. 经历哪些步骤，由谁做、用什么工具、花多长时间？
5. 哪些画面、参数、文件或经验支持结论，哪些只是观点？
6. 有什么困难、取舍、失败或意外，如何处理？
7. 成果能证明什么、不能证明什么？
8. 对品质、价格、保护、传承或创新有什么结论和待核问题？

不追问商业机密、受保护地点或不宜公开工艺；历史、非遗、产地和品质结论发布前回到原始资料复核。

## 从口述素材到故事脚本

1. 让当事人按自己的顺序讲述。
2. 经同意录音并转写。
3. 标注人物、时间、场景、目标、冲突、动作、转机、结果、原话和待核验事实。
4. 识别可用画面或动作呈现的经典桥段。
5. 按时间、因果或悬念重排，不改变事实先后和因果。
6. 展开关键桥段，补足动作、环境、选择和后果。
7. 删除重复，保留唯一中心承诺。
8. 让当事人复核事实和隐私边界。

## 画面感与力量感

### 画面感

- 描述法：把概括改成人物、动作、环境、物品和变化。
- 类比法：用熟悉的具体事物解释抽象概念，并说明类比边界。
- 细节法：从真实素材补时间、地点、物件、数量、角色和生活上下文；具体只降低理解成本，不自动证明真实。

### 故事尖峰

先列完整时间线、目标、行动、约束、反应、结果与证据，再选择最能代表变化、抉择、压力或结果的真实临界点。保留必要前因和后果；没有冲突也可用目标—行动—变化推进，不能合并不同事件或补编敌人、伤害、态度和因果。

### 力量感

- 方言：自然使用且受众能理解时保留，不把方言分高低。
- 动词：准确、具体，不以冲击力夸大事实。
- 数量对比：用可核验的多与少、前与后。
- 时间对比：用明确日期或周期表现快慢。
- 经历对比：呈现处境和能力变化。
- 身份对比：呈现角色变化，不写成职业和阶层尊卑。

数字、时间、收入、身份和结果必须可核验。

## 快速选型

| 真实素材 | 优先母题 |
|---|---|
| 价值观驱动的具体行动 | 平凡英雄 |
| 已消化且愿意公开的长期困境 | 苦难经历 |
| 多个时间节点与行动变化 | 重走成功路 |
| 可处理的未完成愿望 | 弥补遗憾 |
| 偶遇的真实帮助及授权后续 | 帮助弱者 |
| 可控制、可复现的测试或手艺任务 | 极限测评/手艺挑战 |
| 产地、原料、工艺或文化现场 | 追根溯源 |
| 有经历、判断和行业价值的嘉宾 | 超级访问 |
| 可验证的跨文化体验 | 跨文化事实展示 |

## 自检

- 事实、数据和因果可核验吗？
- 有行动和变化，而不只有情绪吗？
- 是否编造困境、反转、失败或态度变化？
- 当事人理解公开范围并同意吗？
- 是否保护隐私、尊严、拒绝权和撤回权？
- 测评条件、标准、误差和边界清楚吗？
- 跨文化内容是否允许不同意见，且没有预设“被折服”？
- 口述重排是否保持真实时间与因果？
- 方言、动词和对比是否准确、不歧视、不夸大？
