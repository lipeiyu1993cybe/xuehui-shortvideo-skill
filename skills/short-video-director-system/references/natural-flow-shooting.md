## 核心定义

自然流不是随便聊天，也不是完全没有脚本。编导先在脑中建立内容结构，再用问题让 IP 自然说出原因、案例、方法、步骤、观点和结果。

`脚本字段 → 主问题 → 追问补字段 → 字段完整后切走 → 剪辑重建脚本`

## 拍摄前准备

### 了解行业

- 浏览近半年较有代表性的内容，避免只看单个大博主。
- 掌握至少一组行业入门概念与常见术语。
- 搜集近期相关事件和可验证事实。
- 课程底稿 `SRC-0001` 给出的参考量是：浏览近半年 10 条热视频、掌握 15 个行业名词或入门知识、搜集 5 个行业热门事件；可按项目复杂度与拍摄周期调整，不作为硬门槛。

### 了解 IP

- 询问成长背景、从业经历、成就、困境和真实案例。
- 分析说话特点、情绪触发点、喜欢与回避的话题。
- 内向 IP 多鼓励、慢推进；外向 IP 可适度质疑和对抗。

### 准备拍摄

- 选择符合 IP 气质且能让其放松的场景。
- 调整角度、光线和背景，检查设备与收声。
- 先聊轻松话题建立信任，不见面就问核心隐私。
- 预先写“问题树”，不写必须背诵的逐字稿。

## 追问

追问用于补齐脚本缺失字段。

| 缺失内容 | 追问句式 | 目的 |
|---|---|---|
| 原因 | 为什么？到底因为什么？ | 引导解释 |
| 观点 | 所以呢？ | 引导判断 |
| 案例 | 比如呢？能举个例子吗？ | 引导具象化 |
| 更多信息 | 还有其他的吗？ | 增加信息密度 |
| 证据 | 真的假的？你怎么确认的？ | 补论据 |
| 方法 | 你会怎么做？能给个建议吗？ | 补解决方案 |
| 结论 | 总结一下？ | 补升华与收束 |

优先追问两类位置：

- 内幕揭秘：回答仍有隐情、利益关系、前因后果。
- 认知盲区：回答缺原因、标准、步骤、案例或适用边界。

## 切走

出现以下信号时进入下一个脚本节点：

- 重复解释：IP 开始说车轱辘话，继续追问不再产生新信息。
- 总结道理：回答已经形成结论，继续追问只会稀释重点。
- 当前字段完整：原因、例子、方法或结果已经足以支撑脚本。
- 情绪下降：继续逼问会伤害表达状态或信任。

切走不是突然换题。先复述一句当前结论，再用关系、假设或对立自然过渡。

## 三类自然流切点

### 1. 亲密关系

替 IP 的亲密关系或目标人群提问，增强场景代入。

- 家庭：公婆、父母、夫妻、兄弟姐妹、子女。
- 社会：领导、下属、客户、闺蜜、朋友、同学、舍友。

用法：描述一个具体人的具体处境，再问 IP 会怎么建议。

### 2. 负面假设

预设时间、金钱、安全或关系方面的坏结果，让 IP 进一步解释观点。

- 时间：学习周期、见效速度、机会成本。
- 金钱：投入、风险损失、返工成本。
- 安全：不确定性、稳定性和潜在风险。
- 关系：家庭、社交和合作影响。

负面假设应有现实可能性，不用虚假恐吓制造焦虑。

### 3. 制造对立

把 IP 回答放入比较框架：

- 地域：南北、国内外、城市与农村。
- 性别：男女认知和需求差异。
- 关系：夫妻、婆媳、老板员工、甲乙方。
- 阶级：高收入与普通收入、资源多与资源少。
- 头牌：名人、名企、名校、名牌。
- 内外行：新手与老手、消费者与从业者。

对立用于显化判断标准，不为争议而扭曲事实或煽动群体仇恨。

## 拍摄禁忌

- 见面就开大：没有信任就问核心选题，容易得到表面答案。
- 人形读稿机：照采访提纲逐字念，缺少真实交流。
- 杠精讨厌鬼：为了证明编导正确而持续反驳 IP。
- 想起来就问：不顾当前思路，突然跳到提纲下一个问题。
- 姿态失衡：过低让 IP 产生说教感，过高让 IP 失去自信。
- 批评情绪、强迫背稿、随意打断、说“刚才没录上”、拍摄时说悄悄话。
- 疯狂摇镜头、主次不清、灯光中途大幅变化。

正确心态：肯定 IP 身份、照顾情绪、与 IP 平等、对齐目标与底线。IP 不配合时沟通原因；IP 强势时不辩论；IP 没话时进入其熟悉的工作场景。

## 镜头脱敏与表现力

表现力先按整体违和分诊，不按夸张、克制、松弛、外貌、音质或明星感评分。检查人物状态、动机、关系、动作、声音、场景、光线与内容任务是否协调；无违和且内容可懂时，不为抽象“网感”返工。

### 常见紧张成因

课程底稿 `SRC-0001` 将镜头紧张归纳为三类常见成因：

- 自我审视过度：过度关注外貌、表达和他人观感。
- 缺乏熟悉感：不习惯面对镜头这类“冰冷的机器”。
- 害怕评价：担心视频发布后被指点、嘲笑或否定。

### 常见问题与处理

- 表情僵硬：开拍前聊轻松话题，先带出自然笑。
- 肢体僵硬：安排端杯、写字、操作工具等动作，或手拿小道具。
- 眼神飘忽：把镜头想象成具体朋友，可在镜头旁放熟悉对象的提示。
- 声音小/语速快：先只录声音，练习深呼吸、停顿、说一句。
- 卡壳：不用逐字背稿，只给三个关键词，由编导提问引导。

### 内心视像

让 IP 说话时脑中“播放小电影”：回忆具体场景、人物、动作和情绪。内心视像会自然改变眼神、语气和故事细节。

### 交流对象

明确这段话在对谁说。对闺蜜、客户、老板或陌生观众，同一件事的用词和情绪不同。交流对象越具体，表达越自然。

### 五项情境、动作、道具与声音

- 出镜前补五项：发生了什么、真实感受、为什么现在说/希望推动什么、具体对谁说、本条最终完成什么。它们用于校准词句、语气、眼线、距离、动作和场景，不要求全部写进成片。
- 真实事实与明确剧情/练习都可使用；不得把虚构家庭、客户、冲突、伤害、疾病和结果伪装成真实经历。
- 设计一项安全、真实的主动作。动作停顿、叠加、走位和道具必须承担信息、证据、关系、情绪或节奏任务并保持连续，没有任务就删除。
- 声音距离由交流对象和场景决定，不机械跟随相机。先按重点、铺垫、转折、结果划分意义单元，再设计音量、音调、重音、快慢与停顿。
- 语速、方言、地方口音、语气词和“一股气说完”不是流量公式。爬楼、压心率、持续发声、呼吸和声带训练不作为通用编导指令；练习须低风险、无痛、可停止。

### 拍摄阶段

- 前期破冰：热点事件、过去经历、头牌八卦等轻松入口。
- 中期提升：保持真诚好奇，适度质疑，及时给表情和语言反馈；避免让 IP 逐题预演，以保留第一次正式讨论的自然反应。拍摄前仍须对齐主题、内容用途和敏感边界，并获得 IP 同意。
- 后期反馈：拍摄者是 IP 的战友，及时肯定具体细节，不做空泛夸奖。

## 场景选择

- 优先选择 IP 熟悉、放松且有真实活动的场景。
- 课程建议大致优先级：室外 > 室内真实场景 > 办公室。
- 可选咖啡厅、饭店、自己的店或工作场景。
- 少用纯大白墙、纯色窗帘、普通书架、卧室门和纯色壁纸等无信息素背景。
- 设备与技术服务于交流，不让复杂设备增加 IP 紧张感。
- 置景可分为素背景、包装型背景和生活化背景：素背景几乎不提供信息；包装型背景必须让真实行业、工作动作或履约证据可见；生活化背景用于自然交流与松弛感。
- 先写目标情绪，再选光线、空间、动作和场景；同一句话在不同环境中会产生不同角色感与语气。
- 人物与背景保持适当距离，形成空间层次；景深和虚化只服务主体与信息，不把设备或布景当作专业证据。
- 测试时固定人群、中心承诺、事实和结构，只替换一个场景；单条播放或点赞差异不能证明场景因果。
- 专业场地不等于资质，生活化不等于可偷拍；始终检查授权、隐私、收声和安全。

### 空间布置、层次与调度

- 镜头拍到的是一个空间，不是一块背景板。勘景依次检查场所真实社会功能、视野/高矮/宽窄/纵深、质地/数量/种类、重复元素、风/烟雾/蒸汽/雨雪/光影等动态介质，以及确有需要的情绪或关系表达；先完成前四项，不为凑模型加布景。
- 空间只能形成观看线索，不能自动证明职业、资质、库存、产能、质量、销量或社会身份；公开/私密场合同时处理交流距离、第三方隐私、场地许可、收声和发布范围。
- 用前中后景与距离、明暗/光区、色彩结构、景深四条路径建立层次；不要求四项齐全，先让主体、动作、事实、关系、字幕和风险信息清楚。镜面、玻璃、窗户、前景与虚化须检查反射泄露、未授权人物和遮挡。
- 重复只在强化真实主题时使用，不能用数量冒充库存、产能、销量或受欢迎程度。动态介质只在增加动作证据、空间状态或目标情绪时使用；喧宾夺主、造成眩晕或带来消防、通风、食品、人员、动物与设备风险时删除。
- 有真实行动线或故事线时，把开始、变化、阻碍、证据、关系和结果分配到必要空间；进入、离开、上下、内外与远近变化必须推进内容，并保持时间、地点、方向、视线、动作和因果连续。分屏显示异时异地时明确标签，不伪装成同步对话。

### 产品与物品的视觉证据

- 先写 `目标人群 → 待理解属性 → 真实条件 → 证明强度 → 误解风险`，再选真实使用过程、统一标准对比、可标注中介、材料/质地/声音、真实使用情境或合规检测；形变属于使用过程。
- 尺具、信封、口袋、手掌、距离、位移、波形、烟雾、动画和替代物都要标明是测量、参照、演示、动画还是比喻。泡沫、颜色、水花、烟雾、光泽和声音不证明清洁、补水、除味、安全、耐久或功效。
- 产品场景只补用途、尺度、操作与环境关系，不虚构拥有者、身份、阶层、生活方式、第三方认可或使用结果；真人须自愿、知情、可撤回，不把残障、年龄、性别、身体、职业与脆弱状态当刺激道具。
- 承重、耐摔、耐磨、耐热等边界展示必须预先声明样本、用途、环境、步骤、指标、失败/停止条件与风险控制；全部对象使用同一流程。危险驾驶、坠落、火焰、爆裂、吞食、暴力破坏或失控测试不拍。
