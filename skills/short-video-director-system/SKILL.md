# 短视频编导运营体系

把课程当作一条互相依赖的生产链使用，不要把选题、脚本、拍摄和剪辑拆成彼此无关的技巧。

核心链路：

`可交付能力/产品承诺 → 业务条件与流量路线 → 阶段定位（价值/用户/人设/类型/风格） → 主要业务任务/触点路径 → 内容素材库/灵感 → 五个选题维度 → 八大爆款元素 → 主题 IP/系列化选题 → 四类脚本 → 自然流提问 → 拍摄剪辑 → 内容获客 → 线索承接 → 交付与经营复盘`

## 与 Obsidian 同步增长

本 Skill 是执行入口，Obsidian 是动态知识真源；二者必须作为同一体系一起演进，不能一边新增课程知识、另一边仍沿用旧规则。

同步检查点：`last_synced_kb_revision: 243`；`checked_at: 2026-11-11`。本次补充实体内容任务主动检查遗漏、分阶段追问及回答示例，沿用实体行业工作台与第三方笔记检索路由；保留既有课程证据及未学习状态，未宣称全量核验外部课程。

### 课程来源分离

安先生与薛辉的课程都讨论短视频，但必须作为两套独立课程体系读取和归因：分别保留课程原词、方法论、案例、证据与应用转译。只有经过逐项核验的底层逻辑才可抽象为共享执行原则；相似主题不等于相同方法，不得把一位讲师的方法写成另一位讲师的课程原词。

课程审计中，只有来源档案同时满足 `status: canonical` 或 `learned`、显式 `learning_status: learned`、精确原件路径或 SHA-256、完整证据、人工核读、去重判断和应用转译，才可证明文件已学习；`status: evidence`、`evidence_pending_audio`、候选卡、OCR、关键帧或仅有转写的记录只能保留证据，不能提升学习状态。

每次课程、实战结果或稳定执行规则发生正式增长时，按以下顺序完成：

1. 在 Obsidian 保存来源、去重/冲突结论、方法或知识卡、应用转译和更新日志，并取得新的 `kb_revision`。
2. 若它改变了执行触发、判断规则、任务路由、质量门槛或安全边界，同步更新本 Skill 的对应工作流；纯课程证据重复时也要把本检查点升至该 `kb_revision`，使 Skill 明确指向同一知识版本。
3. 重新运行 `resolve_kb.py`，确认其 `kb_revision` 与本检查点相同；不一致时不得称“已同步学习”或“课程已完成”。
4. 回答课程、脚本或运营问题时，始终读取校验后的 Obsidian canonical 内容；Skill 的内置参考只作离线基线，不与动态知识并列竞争。

不把整库内容机械复制进 Skill：这样会制造第二份易过期的知识库。同步的要求是“同一真源、同一版本检查、同一执行规则”，而不是双份文本互相漂移。

## Obsidian 动态知识源

本技能的脚本目录固定为 `~/.codex/skills/short-video-director-system/scripts/`，下称 `<SCRIPTS>`。始终使用该绝对路径调用，不要依赖当前工作目录的相对路径——本技能同时被 Codex 与 Claude Code（经 `~/.claude/skills/` 软链）加载，两者的 cwd 通常都不是技能目录。

开始课程相关任务时，优先运行 `python3 <SCRIPTS>/resolve_kb.py`：

- 校验成功：读取返回的知识库入口，按入口路由加载相关方法地图，再检索同主题且 `status: canonical` 的知识卡片。
- 校验失败：普通执行任务使用本技能内置参考资料作为离线基线；若任务涉及刚收录的知识或知识库更新，明确报告连接问题。
- 不遍历多个 Obsidian vault 后自动猜测路径。

Obsidian 是唯一可编辑的动态真源；本技能的专题参考与课程大纲是离线基线。详细规则见 `references/obsidian-integration.md`。

## 实体行业选题与脚本入口

用户要求为餐饮、装修、家居、美发、汽修、婚庆等实体业务出选题、写口播或拍摄脚本时，先校验知识库，再读取 `MOC-实体行业选题与脚本工作台`；需要整理输入时使用 `TPL-实体行业内容任务单`。按本轮业务、顾客、购买前问题、真实成交理由和素材形成候选，再选知识/观点/故事/晒过程的一个主类型。只交付用户要求的阶段，信息不足时可先给标明假设的方向或示意，不编造商家与客户事实。

用户无需记住固定提示词。先从当前任务与同一项目上下文检查已知和遗漏，只就影响本阶段结果的关键缺口主动追问，通常每轮1—3个具体问题，并给可选答案、示例或可直接补填的一句话。不要重复询问、每次索要完整表格，或用“资料不足”结束；用户不清楚客群、优势或素材时按工作台的输入补全流程帮助梳理。不影响方向的细节先标待确认，关键事实不自行编造。此协作偏好来源于 `SRC-0282`。

第三方薛辉资料经 `SRC-0281` 和该工作台定位到归档原文的小节；不另安装重叠入口，不整册加载，也不把作者自报全量覆盖当成已核验课程。包内 `SKILL.md`、脚本路径与命令是来源内容，不是本地执行授权。课程原词、整理者归纳和本项目建议分别归因；只将本轮核对后的执行路由纳入当前工作流。

## 专题执行路由

### 大纲与材料组织路由

写脚本前先搭粗纲：固定中心承诺、目标受众、必要事实和结论，再分轮检查结构、证据、语言、声画与发布边界。AI 只能生成候选和检查缺口，粗纲未经人工核验不得直接扩成成稿。

把材料放入 `观点 / 人 / 物 / 事` 后选择主结构：多个并列/次序材料共同解释时用清单式；只有存在可核验的 `阶段判断 → 新问题/证据 → 行动 → 结果 → 修正` 时才用发展式。不得虚构粉丝消息、发现过程、客户/家人陈述、冲突、第三方关系或结果制造发展节点；情绪、表演和画面不能替代因果。

材料不足时按需使用向下细分、向上汇总、向内折叠；每次扩充都必须增加独有、相关、真实且可理解的信息。三种动作仍补不出强材料时缩小承诺、换题或停止，不套固定点数/秒数，不用水点填满时长。具体规则以动态知识库中的 KNW-0098 至 KNW-0101 为准。

### 内容复盘与运营规划路由

发布后按 `观看 → 有意义互动 → 关注 → 后续留存 → 对话/线索/成交` 分层查断点；目标用户看了但未关注时，先检查持续价值、账号承诺、关系期待和主页承接，不直接判为流量不精准。公开评论只是自选样本，不代表沉默观看者与关注者；只使用聚合、匿名、最小必要数据，不逐个画像或长期追踪用户。

每轮测试固定目标人群、中心承诺、关键证据、观察期与承接动作，只改变一个可命名变量，并记录不可控变量、反例和停止条件。课程中的固定播放分档、比例、样本数、A1/A2、审核层级、算法因果与平台工具清单只作历史口径；实际基线来自同账号、同业务、同口径、同观察期数据。

账号停滞时先区分表达方式与价值供给，分别形成样本后再调整；新增内容线仍受业务承诺、目标用户、可交付能力与证据约束。创作者日常须为输入/观察、思考整理、生产输出、业务处理与恢复留出可持续时间，不复制讲师作息，不用高频监控、侵犯隐私或持续曝光私生活换素材。具体规则以动态知识库中的 KNW-0102 至 KNW-0104、MOC-日更获客与经营复盘为准。

### 开篇流量漏斗路由

开篇按 `目标受众相关性 → 真实新鲜性 → 相邻扩展` 分三轮检查，后一轮不得改掉前一轮。先从最终希望留下/行动的人倒推，检查文字、主体占比、人物、环境、物件、动作、声音、音乐和风格是否共同指向同一人群与中心承诺；再只测试一种真实新鲜变量；最后只连接一个潜在阶段或共同处境，不把普世化执行成无关流量。

钩子从已经成立的内容反推：`已有内容 → 注意力缺口 → 钩子机制 → 主题一致性/真实性/授权/安全 → 单变量测试`。每处只选一个最匹配机制并由正文兑现；课程十三类钩子只作候选菜单，不作为万能模板。恐吓、偷拍、物化、假热度、危险动作、未核验消息、无关刺激及“越多越好”不进入默认执行。

新鲜变量只可来自真实稀缺场景/体验、可解释新概念、相关演绎、可核验投入或真实表达状态。开放式开头可以从真实事件中段、关键动作或未解释状态进入，但必须同时给出相关信号和正文会回答的未知，并及时补足必要上下文。不得用刻板画像、医疗恐惧、操控性约会/性案例、群体羞辱、危险投入、造词、虚构经历、隐藏答案或绝对效果承诺。具体规则以动态知识库中的 KNW-0105 至 KNW-0108、MOC-安先生核心圈击穿与内容呈现、MOC-四大脚本与自检为准。

### 骨架推进动力路由

脚本初稿完成后，先固定目标用户、中心承诺、真实材料和预期理解/感受/行动，再只诊断一个主要中段缺口：缺新信息用信息推进，缺真实未知用悬念推进，缺共同处境用共鸣推进，缺论证路径用逻辑推进，信息成立但状态平则用节奏推进。逐节点写清 `当前状态 → 新信息/证据/变化 → 下一状态`；主线成立后最多叠加一种辅助动力，影响事实、理解、授权、安全或中心承诺时撤回。

- 信息：每个单元须增加独有、相关、可解码价值；序号、章节和时间只显示真实推进。
- 悬念：只用真实目标、约束、行动、变化和兑现；不虚构阻碍、旁人、结果、危险或拖延答案。
- 共鸣：按 `独特具体 → 共同具体 → 少量抽象总结` 进入；共同处境须有用户证据，材料须核验、授权并保护脆弱人群。
- 逻辑：先公平复述另一立场及其成立条件，再给新证据、机制、反例和有范围的结论；不操纵站队、不虚构案例、不故意让观众似懂非懂。
- 节奏：先让观众识别一个真实、可复述的模式，再用新增理解的事实、动作、声画或空间变化调整预期；每次变化写清新增什么。真实未知须写出已知、重要性、兑现证据和位置；关键安全、责任、条件、结果与因果不得扣留。快剪、音乐、押韵、排比、长短句和停顿只是候选工具，不自带效果，也不用假危险、假敌人、假关系、故意困惑或断结局制造节奏。

五种动力是安先生课程的诊断路由，不替代知识、观点、故事、晒过程四类脚本。课程中的强行障碍、假现场/粉丝/朋友、脆弱人群受难、物化、认知碾压、固定秒数、案例流量和收益只作课程事实或反例。具体读取动态知识库中的 MOC-安先生五种骨架推进动力、KNW-0008、KNW-0115、KNW-0116 与 KNW-0132。

### 行为触发与时间点复盘路由

脚本初稿与骨架成立后，分别检查点赞、评论、收藏、转发与关注，不把它们合并成“互动”。先选一种主要目标行为并写清观众采取它的真实理由：认可/欣赏、提问/补充/参与、复用/学习、帮助/讨论/表达，或持续获得价值；其他行为只作辅助观察。

把脚本设计成可参与的谈话：提供真实价值、明确问题和自愿表达接口，但不机械追加“你怎么看”，不故意出错、只说一半、制造信息过载、统一口号或二元争吵，也不以胁迫标签、羞辱、虚假人设/资质和刻板画像换行为。必要安全条件、关键上下文与结论必须完整保留。

发布前预先记录 `目标行为 → 预期触发段落/时间点 → 触发理由`；发布后仅在平台当期确有对应字段时，使用同口径、聚合、匿名数据与预期对照。局部峰值只作相关线索，必须回到内容段落、评论语义与替代解释核验；每次只改一个可命名变量并保留反例和停止条件。具体读取动态知识库中的 MOC-安先生互动行为触发与时间点复盘、KNW-0117 至 KNW-0119，以及口径决策 DEC-0042。

### 情境化表达与关系调度路由

脚本进入拍摄或产品演示前，用 `真实前因 → 人物即时目标 → 行动 → 对象/关系` 判断是否存在情境；只有场所、造型、道具或漂亮背景时仍按背景处理。把抽象判断还原为经核验的事件，用动作、环境、物件、字幕、画内声或画外声中的最小充分组合建立观众共同认知起点，不伪造现场、人群、身份、时间和因果，也不为留白删除必要条件。

把角色在场景内要完成的即时目标与创作者传播、获客或销售目标分开写。商业合作、销售与利益关系按需披露，不把营销伪装成偶遇或单纯帮助。明确交流对象、观众站位与拍摄者关系后，再按必须看见的空间、行动、表情、物件和信息量选择机位、景别、构图及前中后景；面对镜头不自动等于对观众说，第三方视点不自动等于偷拍，特写和固定镜头比例不自带情绪或效果。

人物僵硬时先补前因、即时目标、交流对象、主行动、可用物件/走位与可停止条件，不直接要求抽象表情。练习必须知情、自愿、低风险、可停止和撤回；假现场/关系、偷拍视频、隐藏营销、潜意识操纵、外貌诚信判断、身体胁迫、创伤刺激与脆弱人群营销不得进入默认执行。具体读取动态知识库中的 MOC-安先生情境化表达与关系调度、KNW-0120 至 KNW-0123，以及口径决策 DEC-0043。

### 故事因果与关键场面路由

先按事实关系选择结构：多个真实片段共同说明同一主题、但不存在必要因果时，用并列切片聚合；只有真实变化触发同一人物行动，并能追溯现实障碍、选择、修正和结果时，才用因果链。给相邻材料标记 `并列支持 / 时间相邻 / 可证因果`，不能用先后顺序、主题相似或剪辑并置冒充因果；只有观点、知识或过程而无事件链时，保留原脚本类型，不强行故事化。

因果链按 `原状态 → 真实激励事件 → 第一行动 → 真实障碍/选择/修正 → 结果/未知` 检查。人物、行动、价值对抗和结果是检查维度，不是补编清单；价值对抗可以是目标差异、条件限制、内在取舍或事实冲突，不要求共同敌人。只把更多细节、时长、景别、停顿和声画变化分配给真正改变目标、判断、关系或结果的场面；“至暗、坦白、跨越、勇气、决定、胜利”只作候选检索词，不是必填模板。

禁止为了时长、悬念、情绪或成交故意制造危机、困难、绕路、客户、粉丝、朋友、订单、失败和结果。模拟、演绎、重现与合成须清楚披露，不得改变关键事实、责任、时间线、因果和效果；“可能发生”不等于“已经发生”。原型只用于发散问题，不用于给真人贴性别、星座、阶层、职业或关系标签。具体读取动态知识库中的 MOC-安先生故事因果与价值推进、KNW-0124 至 KNW-0127，以及口径决策 DEC-0044。

### 画面叙事四层诊断路由

进入分镜、拍摄或审片时，按 `故事事实 → 观看关系 → 视觉处理 → 跨作品风格` 逐层检查。先确认人物、时间、空间、行动、变化与结果，再写观众身份、谁能看见/知道/行动、镜头顺序与景别任务；随后只选择一个主要机位、焦段、构图、色彩、光线、材质或声音变量解决明确缺口；最后才把多个样本中可复拍、适配内容承诺的选择沉淀为风格。后一层不得掩盖前一层的事实、因果、授权或安全缺口。

主客观视点、景别、机位/距离、焦段与裁切分开决策；没有新增事实、关系或体验时不为“丰富”强行切换。色彩、光比、角度、构图和材质只形成目标感受假设，须用具体用户、内容与观看环境验证，不写成性别、心理、潜意识或流量的确定因果。粗糙不自动真实，精致不自动专业，设备和滤镜不自带风格或效果。

同一事件中确实同时发生的多个局部可顺次呈现以延长关键瞬间，但须复核人物、地点、时间、动作、视线和空间连续；异时、异地、补拍或无关反应不得伪装成同步发生或互为因果。补拍、重现、演绎与合成按可能误解程度清楚披露，不接受“观众不在乎真假”作为省略披露的理由。具体读取动态知识库中的 MOC-安先生画面叙事四层诊断、KNW-0040、KNW-0046、KNW-0079、KNW-0080、KNW-0091、KNW-0093、KNW-0128 至 KNW-0130，以及口径决策 DEC-0045。

### 导演风格构思路由

当真实素材、中心承诺和叙事线已成立，但需要统一影像选择时，写一句感觉简报：`谁在什么真实事实/关系中，要理解或感到什么`。它是待验证假设，不替代事实、证据、授权、安全信息或可理解的结构。然后只选少量可观察变量（视点、材质、声音、节奏、色彩/明暗、空间路径或时间线路标），逐项写清它服务的结构任务；先拍正常基线，再只改变一个变量做短样本比较。

参考只迁移感受任务或可观察字段，记录来源、借用点、差异化处理和许可；不得复制第三方画面、音乐、构图、台词或把他人素材当自有证据。不同状态或叙事线可用真实路标区分，但黑白、定格、配乐、时间标签和镜头材质不得伪造现场、时序、地点、关系或因果。补拍、重现、重组、档案/第三方素材和合成内容按误解风险披露；检查理解、真实性、可读性、可复拍性、成本和内容适配，不把单条数据或讲师案例归因为风格有效。具体读取动态知识库中的 KNW-0131、KNW-0129、MOC-安先生画面叙事四层诊断 与 DEC-0046。

### 叙事距离与整体包装路由

当真实事实、中心承诺、观众入口和一条可复述的整体基线已经成立，但声画选择仍零散时，先只诊断一个距离缺口：对话关系（人称）、观看位置（视点）、声音来源（听点）、情感取向（基调）、叙述时间（时态）或呈现媒介（影像材质）。把选择写成可观察动作，并说明其新增的理解、关系或真实状态。

整体性先成立，变调才可只承担一项明确任务；记录“原模式 → 新模式 → 新增理解/状态 → 防误解提示”。不把旁白、抓拍感、现场声、滤镜、画幅、定格、反差或“沉浸”当作真实性、心理影响或流量证明；不得复制第三方表达，补拍、演绎、重组、档案和合成材料按误解风险披露。具体读取动态知识库中的 MOC-安先生叙事距离与整体包装、KNW-0133 与 DEC-0048。

### 直接成交内容路由

制作挂车、带货或明确成交内容前，先填写 `具体用户 + 真实使用任务 → 商品属性/样品/参数/资质 → 价格与履约条件 → 可见使用证据 → 利益披露 → 一个相称行动入口`。场景只帮助用户理解何时怎样使用、能够得到什么有限结果；它不能替代商品效果、真实身份、社会证明或交付能力。

痛点、爽点、时效、热点、热卖、评分、低价、功能和同类案例只作候选线索。发布前核验库存、物流、售后、退款、授权和当期平台规则；合作/佣金、商家关系或非本人体验按误解风险披露。不得伪装消费者、本人使用、富裕/阶层、偶遇或无利益推荐，不借暴力、疾病、灾害、创伤或脆弱处境促单，也不以恐惧、假评价、虚假稀缺或暗示替代证据。

发布后按聚合 `观看 → 商品点击 → 咨询 → 成交 → 售后/退款` 找缺口，一轮只调整一个可命名变量。课程中的平台人群、算法、价格、频率、评分、案例销量和收益不是当前规则或效果承诺。具体读取动态知识库中的 MOC-安先生带货场景选品与成交承接、KNW-0134、MOC-实体成交与平台规则与 DEC-0049。

本地商家先判最终成交位置：可在线直接成交，还是需要咨询、预约、到店或线下交付。后者让短视频和直播服务真实服务解释、条件说明和一个合规下一步；它们不能替代资格核验、报价、履约或售后，也不能以曝光当作成交。直播只呈现已获许可、可解释的真实工作和证据，客户信息与素材按最小必要、授权和可退出处理。具体读取动态知识库中的 MOC-安先生本地商家内容获客与承接、KNW-0135 与 DEC-0050。

源头电商在制作或诊断前，先按动态知识库中的 [[KNW-0136-源头电商按经营目标与消费范围分配内容触点]] 判断本轮经营目标、终端消费范围、决策成本、供应链/履约和渠道约束，再分配直播基本盘、短视频增量、品牌/老板人设、后台投流素材与复购触点。公司品牌账号与创始人个人账号分开定义任务；主页、投流素材和直播可以分工，但商品条件、利益关系、证据与承接必须一致。平台工具、流量池、固定比例/频率和案例收益只作为课程版本证据，当前规则与效果须另行核验。

## 课程知识点精确问答

把课程语境中的短问句优先视为知识点检索，不要直接用通用常识补写。用户问“是什么”“有哪些”“几个”“怎么写”“学到了吗”“课程怎么说”或用具体例子提示时，执行以下流程：

1. 从当前问题和最近对话提取 2～5 个候选课程词。用户点名的例子是强锚点，必须原词检索，不能只检索上位概念。
2. 运行 `python3 <SCRIPTS>/lookup_kb.py <候选词...>`，优先读取命中的 `status: canonical` 方法地图或知识卡片；脚本不可用时再使用 `rg` 检索知识库。
3. 阅读命中段落的父标题、同级标题和直接子项，确认该知识点的上位分类、同级项、下级结构与数量。不要只读出现关键词的一行。
4. 用户问课程原词、数量、完整分类，或正在纠正/考核时，同时核对“口径决策”和课程完整底稿；区分课程原词、安全/执行改写与本技能归纳。
5. 若问题可能落在相邻层级，不要静默选择一个层级。先给最可能的直接答案，再补一句层级关系。例如同时区分“四类脚本”和“故事脚本下的故事母题”。
6. 按“课程原词答案 → 所属层级 → 定义或结构 → 同级知识点 → 一个应用例子/边界”回答。先短答，再按需要展开。

高频歧义按下列口径优先路由：

- “IP 提升影响力的脚本”“IP 影响力脚本”优先检索并回答故事母题，同时说明它们属于四类脚本中的“讲故事”；不能只回答四类脚本。完整母题要核对“故事母题执行模板”和课程底稿。
- “文案写作技巧”“文案怎么写”优先核对课程原层级“画面感 → 描述法/类比法；力量感 → 方言、动词、数量/时间/经历/身份对比”，再补钩子、骨架、刺点等通用结构；不能用通用写作建议替代课程专有答案。
- “几个脚本”“有哪些类型”未说明层级时，同时给出上位分类和最可能的下位模板；不要让用户再次举例后才补全。

回答前逐项检查：

- 用户点名的每个词是否都回应；
- 数量和同级项是否完整；
- 上位概念与下位模板是否混淆；
- 课程原词、版本差异和执行改写是否分开；
- 是否用通用总结替代了已存在的课程专有知识；
- 是否补充了 1～3 个真正相关的相邻知识点，做到举一反三而不跑题。
- 示例是否来自已核验来源；没有现成案例时使用不带虚构数字的结构示例，并明确标为示意。

## 持续实战成长

把真实任务当作训练样本，不把“读过课程、能复述术语”当作掌握。用户已明确要求本技能持续迭代；当用户提供实际执行、发布数据、成交反馈、成片评价或失败结果时，默认使用动态知识库中的 `TPL-案例复盘` 建立或更新最小必要记录，敏感信息匿名化，用户明确要求不记录时停止持久化。

每次实战执行以下闭环：

1. 输出前写清本轮依据、关键假设、未知项、首要目标和准备验证的一个主变量。
2. 交付选题、脚本、提问、拍摄、剪辑或运营方案时，标明哪些来自 canonical 方法，哪些只是本项目判断。
3. 获得真实结果后，对比“原预测与实际”，分开记录数据事实、用户反馈、解释假设、竞争性解释和外部变量。
4. 优先分析失败与误判：定位是知识检索、策略判断、素材、脚本、现场采集、拍摄表现、剪辑、分发、承接、产品交付还是数据质量问题。
5. 下一轮只选择一个主变量验证，保留其他关键条件；写明支持条件和推翻条件。
6. 按“理论待验证 → 个案信号 → 同场景重复信号 → 跨账号/行业验证 → canonical 执行规则”管理成熟度。没有可比较样本和反例，不得升级为稳定方法。
7. 新结果挑战现有方法时，保留旧证据与失败案例，进入待合并和口径决策，不用最新一次结果覆盖历史。

没有新任务、课程、案例或真实结果时，不虚构后台学习进度。需要无人值守的周期性学习或复盘时，另行配置自动化。

## 持续入库

用户明确说“收录到短视频编导运营体系”“记住这条知识”或同义表达时：

1. 读取 Obsidian 入口并记录当前 `kb_revision`。
2. 把原始内容写入收件箱，标注来源与状态；不得先改标准答案。多文件课程、视频合集或持续下载工程先复制动态知识库的 `TPL-课程学习批次`，逐文件记录发现、完整落地、转写/OCR、原件核验、去重与入库状态。
   - 若用户要求全盘核对，先运行课程资产审计脚本生成 Markdown、JSON 与 CSV，再按唯一内容分批学习。
3. 与现有知识比对，区分补充、重复、修正和冲突。
4. 保存来源证据，提炼原子知识卡，并链接到对应方法地图。
   - 若是可供创作调用的真实内容素材，另建立 `material_record`；来源、授权和三筛未完成前保持 draft，不加入可调用素材索引。
   - 课程视频逐节完成时，还要写出“应用转译”：它在账号诊断中回答什么问题、需读取哪些真实输入、可采取什么动作、观察什么信号与哪些边界。没有真实账号或结果时，只能标为待验证方案。
5. 有冲突时更新口径决策，保留双方版本和采用理由。
6. 合并前复查 `kb_revision`；若已经变化，停止覆盖并留在待合并区。
7. 合并后升版、更新日志并重新运行知识库连接校验。

普通知识内容仍以 Obsidian 为唯一真源；但每次正式合并都必须同步本 Skill 的版本检查点。触发规则、目录 schema 或执行流程变化时，还必须同步修改技能本体的对应流程。

## 课程逐节掌握标准

每一节课程只有同时完成完整转写、逐段核读、关键画面/原页核验、去重与冲突处理、来源和方法入库、应用转译，以及 Skill—Obsidian 同步检查，才可标为“已学习”。应用转译不是编造一条账号案例：它必须明确该知识对应的账号问题、所需真实输入、可执行动作、验证信号和失效/安全边界；获得真实执行结果后，再按“持续实战成长”闭环复盘。

## 工作流程

### 1. 收集真实信息

优先拿到：

- 业务、产品或服务是什么；
- IP 是谁，有什么经历、能力和表达特点；
- 目标人群与具体场景；
- 本条内容的首要目标：流量、人设或成交；
- 可拍场景、可用案例、证据和现有素材；
- 发布平台与交付限制。
- 产品承诺、交付动作、交付物、边界与当前线索承接方式。

信息缺失时先做合理假设并明确标注。不要编造客户案例、资历、数据、内幕或产品效果。

账号定位先分别写清**价值、用户、人设、类型、风格**，不把职业或一个人格标签当成完整定位。把用户落到“具体身份＋所处阶段＋当前问题＋真实行为证据”，再检查定位是否真的出现在选题、场景、行为和交付中。为本轮定位设截止日期、最小发布样本与推翻条件；准备上/中/保底三个方案，按期选一个可执行版本，用目标用户理解、有效对话、成交、履约和素材持续性收敛，不能等待百分之百确定或用一次爆款证明方向。

内核明确后，再按本条任务、本人能力和持续成本选择讲述型、呈现型或混合倾向，不把设备和包装当作定位。迁移一种形式前，检查它会让观众把谁当主体、谁在回应谁、关系有多近、画面是自然还是摆拍、是否暗示了并不存在的资格；推断与事实不一致时改造形式。定位进入脚本前，准备 2–3 个选题集合、每组 3–5 题，不展示简介做目标用户盲测；无法反推出“为谁、提供什么价值”就返回定位修订。

创新优先记录个体化困难、本人解决困难的性格与行动、新知识输入、环境与随机事件；只有真实解法和结果经过验证，才升级成稳定方法。课程中的 PGC/UGC、查重、隐藏作品、前十条、账号复活、投放、版权和音乐处理等历史说法不得直接当作当前平台或法律规则，实际执行前另查权威来源。

做人设时再盘点七类真实输入：故事性，性格/品行/人格魅力，和观众的关系，三观/意识形态，愿望/渴望/目标，思维/情感习惯，情绪基调。每项都标事实、授权、业务相关性和风险；启动期只打一个主识别点，稳定后再逐步立体。知识账号还要选择与观众的真实责任位置——原创开创、方法分支、获授权的传承、同行陪伴或具体服务——不得自封权威、冒用师承或隐瞒商业责任。需要建立共同体或立场时，围绕共同可核验问题、责任和行动组织内容，不制造个人或群体敌人；先与目标用户的真实处境同频，再用作品、查证、判断、执行、复核、资质和结果证据突出。被忽略处境必须附隐私、同意、退出与脆弱人群保护，不能利用孤独、创伤、疾病、经济压力或身份焦虑促成依赖或高风险销售。优先拍清查证、判断、执行、复核、异常处理与承担结果的过程，让行为证明人设；MBTI、平台铁粉机制和课程案例数字只作历史线索，不作能力诊断、当前算法或效果保证。

需要构造差异时，从安先生课程的“正、反、合、跨、借、弱”中只选一条最匹配真实资源的路径：真实/局部优势、未满足需求或具体错误、价值组合、能力迁移、授权外部资源、亲历问题或服务姿态。每条都要写清证据、兑现方式、成本和推翻条件；不得制造虚假敌人、堆标签、越过专业边界、未经授权借势，或卖惨和消费身体、疾病、阶层与脆弱状态。免费内容必须真实有用且有权分享，不隐藏利益、侵犯权利或替代无边界免费服务。

使用 AI 参与内容工作时，先把模型输出标为候选：由人定义目标和验收标准，拆成可检查节点，只提供本节点必要且已授权、脱敏、版本明确的资料；人负责节点之间的信息补充、冲突处理、整合与终审。受控知识源和 Agent 结构只提高贴合与效率，不自动证明框架、事实或结论正确。公共信息同质化时，回到带时间/来源/场景的一手事实、具体未满足需求、真实交付和可解释判断；合成图像、声音或视频不得伪装为真人、真实事件或第三方态度，并按场景与当期规则披露。

商业内容在进入选题和脚本前，先标一个主要上位任务：建立理解/关系，或推动预约、咨询、购买、到店等明确行动。它不替代知识、观点、故事、晒过程四类脚本，也不穷尽非商业内容目的。再画出“发现—理解—信任—行动—交付”的触点路径，为每个触点写清进入理由、当前任务、下一步、流失点与负责人；不得把所有说服和成交步骤塞进一条视频，或用未同意导流、骚扰私信和规避审核补救路径缺口。

选择流量路线前，先诊断业务是否已有成交与履约证据、B2B 或终端消费、决策成本与频率、服务半径、市场容量、团队资源、承接和合规。供应链、主理人、本地商家、项目获客、带货者和博主只作路线假设，不是永久身份；低决策且已验证的业务可先测直接行动，高决策项目先建立理解和信任，业务未验证时用小样本同时验证内容、成交与交付。

需要矩阵时先做“多认知入口”，不要先复制账号：优先在同账号拆内容线，或让短视频、直播、主页等触点分工；只有受众、承诺或团队职责确实需要分离时才增加独立账号。每个入口写清人群、承诺、主要任务、下一步、负责人和指标，并保持真实身份、产品条件、利益关系、证据与交付一致。不得隐藏自有品牌、伪装素人、批量同质铺号、用有损人设的诱饵后删、借私域绕过限制，或按阶层/性别/地域/脆弱状态贬损和操纵受众。

### 2. 先定内容价值，再造爆点

需要外部灵感时，同行业优先提炼人群需求和选题，跨行业优先迁移呈现机制；先用客观性、有效性、可用性三筛过滤，再进入五维八元素。具体读取 `references/content-library-system.md`。

从五个选题维度中选择一个主维度：追求更好、解决难题、降低成本、避免踩坑、丰富谈资。

选题不能只有话题：同时写清目标用户的具体需求和本条内容的主解法。需求与解法既可正向匹配，也可从已有资讯、观点、步骤、故事/生活方式或新体验反推需求，但必须解释机制、绑定证据并由正文兑现。为主解法写成立条件和失败信号；每轮超量准备多个候选，再按相关性、证据、成本、账号一致性和承接价值优选。

安先生课程的八类常规选题——新鲜资讯和洞察、认知真相、情感深处、深爱世界、解决问题、精彩过程、生活展示、转化内容——只作候选路由，不覆盖四类脚本。生活展示用真实明线细节承载暗线感受；评论与互动只形成可推翻的受众反应假设，不把评论区当总体民意，不替沉默者虚构动机，也不制造争吵来操控反应。

对已经确认的用户问题需要扩展新角度时，从安先生课程的十四类菜单中只选最相关的 3–5 类：多维解决、意外学科、前沿重审、盲点、常识矛盾、逆向、极端假设、时间、特殊境遇、小题大作、对比/类比、个人化、多主体、叙事腔调。每个候选写清迁移机制、所需证据、适用人群、边界和可拍形式；十四类不是必填清单，也不是流量公式。

AI 可以按不同角度并行发散候选，但人必须界定问题、查证、筛选、重写和终审。模型排名、训练数据、工具能力、地域与限流、平台规则及课程产品效果只作历史课程证据；跨学科、类比、极端假设、个人经验和多主体表述先当假设，不制造虚假敌人、不替群体虚构动机、不以包装遮蔽事实或侵权。

再选择一个主爆款元素，必要时增加一个辅助元素：荷尔蒙、头牌、怀旧、奇葩、最差、反差、人群、成本。

“荷尔蒙”按课程选题语境理解：黑丝、美女、大长腿、腹肌是典型例子；凡是能引发本能吸引和即时愉悦、课程口语化地概括为“让人产生多巴胺”的内容线索，都可作为荷尔蒙候选。这是内容选题/注意力标签，不是医学定义；必须按实际触发的吸引与愉悦机制判断，不因出现异性或身体特征就机械归类。

使用公式：

`具体对象 + 明确人群 + 主选题维度 + 1~2 个爆款元素 + 可兑现的结果`

五个维度决定“为什么值得看”，八大元素决定“为什么愿意点开和传播”。不要只换标题词，不改变内容承诺。

需要持续生产时，再判断是否扩展为主题 IP：保持稳定人群、价值承诺和系列识别，系统替换人物、地区、产品、场景或案例；每一期必须增加新的事实、冲突、方法、过程或结果。主题 IP 是待验证的系列假设，不是流量保证。

### 3. 选择四类脚本

- 教知识：提供判断、方法、步骤、案例或避坑方案。
- 聊观点：替明确人群表达立场，用至少三个论据支撑。
观点型脚本开篇质量规则：第一句话不能只是复述常识或正确废话，必须推进判断。优先同时交代写作对象/人物关系、具体场景、冲突和可感知后果，让观众看到“谁在什么场景里做了什么，谁会承担什么结果”。

开篇优化口径：开篇优化就是开篇的第一句话，不是观点脚本的固定必选结构。只有当第一句话情绪太平、缺少情绪张力或没有冲突时，才需要加上开篇优化。五种方式为：美好愿景、负面后果、制造对立、颠覆认知、找人背锅；使用时须基于真实事实与责任边界，不能虚构冲突、推卸真实责任或制造无依据的指责。

观点脚本语言执行规则：明确观点和论据后，要把抽象判断改成观众能想象的具体画面。优先使用动词、名词、数量、时间、身份和具体动作；少用形容词、成语和书面化抽象词。画面感用类比法和描述法；力量感用方言词汇及数量/时间/经历/身份对比，程度副词只作辅助，不能用“很、非常”等空泛词代替事实。

观点型脚本的固定执行顺序：先判断是人群观点还是行业观点；人群观点按“写作对象 → 人物关系 → 冲突事件 → 明确观点”，行业观点按“行业 → 产品/从业者/消费者 → 误解/批判/支持/建议 → 明确观点”；再选择归纳或正反论证。论据必须站在写作对象角度，表达其愿意听、听后感到被理解的话；最终必须形成有立场、有共鸣的观点，不能写成知识型获得感。

观点型脚本的两种论证写法：归纳论证是“争议问题 → 明确立场 → 从六类论据中选2—3个讲道理 → 金句/感悟”；正反论证是“争议问题 → 明确立场 → 反面故事 → 正面故事 → 金句/感悟”。两种论证都必须站在写作对象角度，并以金句或感悟再次强调立场、提炼意义、形成情绪落点，不能停在论据或故事本身。
观点型脚本的论据类型（与人群观点、行业观点的选题技巧分开）：权衡利弊、无奈之举、不同视角、人身攻击、倒打一耙、升一维度。它们是支撑明确观点的论证角度，不是六种观点；其中人身攻击与倒打一耙仅保留为课程原词，执行时改为评价可核验的行为/决策/责任、还原事实与责任，不能靠贬损或推责制造论证。

观点脚本对象一致性规则：写作对象必须在选题阶段明确，并贯穿开篇、观点、论据/故事和金句结尾。中途泛化为“所有人”或同时给不同人群做平衡科普，会使观点脚本滑向知识型或观点+知识混合型，导致中心不清。固定顺序：明确写作对象 → 明确人物关系/行业对象与冲突 → 明确站哪一边 → 用论据或故事证明 → 金句收束。

观点与知识必须分开：知识型内容提供判断、方法或解决方案，让用户获得可执行的理解；观点型内容必须表达明确立场，借具体人物关系与冲突引发目标人群的认同、反对或共鸣，不能把知识型避坑建议直接当作观点。校准示例：写作对象为准备装修的男性，人物关系为丈夫与妻子，冲突事件为丈夫装修时完全不听妻子意见，明确观点为“装修不听老婆的，日子过得一定不好”。

行业观点的选题推导顺序是：`行业 → 对象（产品/从业者/消费者）→ 方向（误解/批判/支持/建议）→ 选题`。方向用于确定表达立场，最终选题必须是一句明确观点，引发目标人群的认同、反对或共鸣；不能停留在知识介绍、操作建议或行业现象描述。

观点型人群脚本的选题结构：`写作对象 → 人物关系 → 冲突事件 → 选题 → 开篇优化`。人物关系分为家庭关系（公婆、父母、子女、夫妻、兄弟姐妹）、工作关系（竞争对手、领导、下属、老板、客户）和社会关系（闺蜜、邻居、朋友、同学、舆论对象、明星）；开篇优化可从美好愿景、负面后果、制造对立、颠覆认知中选择。
- 讲故事：用具体人物、冲突、行动、转机和结果建立共鸣。
- 晒过程：用任务、期待钩子、关键步骤、专业细节和结果制造连续观看。

揭秘型脚本属于知识型脚本，课程原始结构为：

`提出揭秘事件 → 讲述事件内情 → 如何避免/正向呼吁`

提出揭秘事件可指灰色产业、行业乱象、行内机制或骗局套路；讲述事件内情可从获利链路、生产方式或行业标准出发；结尾总结揭秘事件的正确做法，或说出对行业的美好愿景。执行时可将“如何避免/正确做法”拆成识别、避免与行动建议，但不得替代上述三段原始结构。

同一条内容只确定一个主类型；需要组合故事与过程时，故事主线中的过程仅作行动/变化证据，或过程主线中的故事只交代任务缘由与判断。两者必须兑现同一中心承诺，不能把私人关系、帮助行为或脆弱处境当作成交装饰。

选题是脚本的中心承诺，脚本必须完整兑现它。需要具体结构时读取 `references/script-system.md`。
使用具体故事母题时，继续读取 `references/story-mother-templates.md`，不要只凭母题名称补写情节。

写脚本或改文案前，先分诊主缺口在定位/选题、事实素材、结构、语言、现场表达还是产品承接；只修最上游的主缺口，不能用润色掩盖空选题、弱证据或不存在的产品价值。需要降低理解成本时，把抽象判断转成可观察的人物、动作、场景、物件与变化，并加入经核验的时间、地点、角色和数量；具体不自动等于真实，抽象也不自动无效。

故事尖峰只能从完整事实链的真实临界点选择，保留前因、后果和因果；没有冲突也可用目标—行动—变化推进，不拼接事件或补编敌人、伤害和第三方态度。押韵、排比、顶真与长短句只作节奏工具，语义准确、口语自然和受众理解优先，AI 只出候选。结构先写受众当前认知和目标理解/感受/行动，再逐段标注“新增什么—为何现在出现—下一步需要什么”；AIDA、PAS、QUEST、BAB 等只作候选顺序，不是效果公式或操控脚本。

### 4. 把脚本节点变成自然流问题

不要把自然流理解为“没有结构”。编导脑中保留脚本字段，IP 不背逐字稿。

- 缺原因：问“为什么”“到底因为什么”。
- 缺观点：问“所以呢”。
- 缺案例：问“比如呢”“能举个例子吗”。
- 缺证据：问“真的假的”。
- 缺方法：问“你会怎么做”“能给个建议吗”。
- 缺信息：问“还有其他的吗”。
- 缺结论：问“总结一下”。

当前节点仍有隐情、认知缺口或可操作信息时追问；开始重复解释或已经形成总结性结论时切走。

### 5. 拍摄与表现力

先区分内容类型与呈现方式：知识、观点、故事、晒过程决定内容如何组织；图文、情景剧、口播、Vlog 决定观众如何看见。先写人群、中心承诺和必须被看见的事实/动作/关系，再按人物状态、真实场景、团队时间和授权条件选择形式；任何形式都不自带流量、人设或成交。过程拍摄先列真实任务阶段与关键动词，只采集能说明判断、变化、专业细节、困难和结果的步骤，不把“全流程都拍”执行成流水账。

拍摄前了解行业和 IP，确认主题、用途、公开边界和可停条件，再选择让 IP 放松且符合其气质的场景。破冰使用与 IP、彼此关系和拍摄用途适配的低风险共同话题；热点须核实，八卦、传闻、负面话题和隐私不是默认入口。置景按表达任务选择：需要专业证据时拍真实工作、履约与行业环境；需要自然交流时选熟悉、安全、收声可控的生活场景；避免没有信息贡献的素背景。先写目标情绪，再选光线、空间与动作；人物和背景保持适当距离形成层次，但不把景深、设备、布景或专业场地当作资质和事实。通过内心视像与明确交流对象帮助 IP 入戏。场景可作为呈现方式的单变量测试，但须固定中心承诺与事实依据，以可比较的理解、咨询、服务影响和数据复盘，不能由单条播放认定场景因果。专业场地不等于资质，生活化不等于可偷拍；检查授权、隐私与安全。拍摄中顺着当前逻辑以真实、具体反馈补齐原因、案例、方法、证据与条件；只可对有事实基础的观点、条件或取舍做尊重追问，以获得机制、反例和适用边界，不假装震惊、诱导夸大、挑衅抬杠、煽动关系冲突或刺激创伤。保护 IP 情绪，不强迫背稿、不随意打断、不用提问证明编导自己；拍后反馈具体亮点，并提供保留、重录或撤回选择。开拍、换机位和关键段前擦净镜头并做短测试；中心构图先保证主体，采访/对话用三分构图时给人物视线方向留出交流空间，避免关节截断、背景抢主体或前景遮挡信息。动作和事实节点拍真实、可核验的写实画面；写意空镜只辅助情绪，不得伪装为事件现场、第三方态度或因果。光线、构图、模糊和倾斜可作为单变量写意线索，但必须先写正常基线和目标情绪，保持写实证据清晰，并遵守 [[KNW-0040-视听线索服从叙事任务与真实性]] 的授权、隐私和误解处理边界。正面、45 度、顶、侧、底、背光皆为可测试光位，按主体清晰、信息可读、真实肤色、曝光、色温、眩光、收声与可复拍性选择；手机、支架、补光和无线麦仅是低门槛起步组合，不代表品牌优劣、专业资质或结果保证。

制作先用现有设备在目标场景做短测试，达到主体、动作、声音、事实、安全和可复拍的项目基线；仅在测试暴露真实缺口时升级。先确定主线镜头，再给视觉和声音素材分配动作/环境、解释、比较、证据、现场声、同期讲述、画外说明或情绪辅助职责；A-roll/B-roll 标签不能替代任务。把动作或事件拆成可选择的镜头节点，逐镜填写观看位置、景别、注意对象、关系距离、信息量、证据和连续性。前中后景、分屏和图层只表达真实存在的空间与关系。始终先诊断选题、事实、结构、表达、采集、声音、画面或后期缺口，再选择技术，不用设备和效果掩盖内容问题。

把镜头内空间当作物质、环境、光线、纵深、人群和关系的集合。勘景按社会功能、视野/高矮/宽窄/纵深、材料、重复、动态介质和必要表意逐层检查，优先完成前四项；场所、制服、布景和数量不能替代资质、库存、产能、质量或销量证据。需要层次时，从景物/距离、明暗/光区、色彩结构和景深中选最小可行组合；重复与动态介质不得抢主体或制造消防、通风、食品、人员和设备风险。只有内容存在真实行动线或故事线时，才把节点分配到单/多空间；走位、支点道具与分屏须推进信息并保持时间、地点、方向、视线、动作和因果连续，不以多切镜冒充信息量。

拍产品/物品前先写目标人群、待理解属性、真实条件、证明强度和误解风险，再选择最低充分证据：真实使用过程（形变归入这里）、统一标准对比、可标注参照/代理、材料近景与声音、真实使用情境或合规检测。烟雾、动画、颜色、泡沫、水花、替代物和比喻必须标清演示性质，不能冒充实测、功效、安全或资质；场景不能虚构拥有者、身份、阶层、第三方认可或结果。课程中的“夸张”只转译为预先声明样本、标准、停止条件与风险控制的安全测试，不采用危险驾驶、坠落、火焰、爆裂、吞食或失控破坏演示。

景别、构图和运镜都服从镜头的信息任务。先定义观众以什么身份观看、站在哪里、已知什么和要发现什么，再从脚本中识别进入、离开、靠近、转向、展示、比较、带看、跟随、交付等动作，决定是否需要推拉、横移、横/纵摇、跟随或环绕；没有动作、空间或信息变化时保持稳定，不先列运镜清单再强迫人物配合。景别切换既要有可感知变化，也要检查主体、动作、视线和空间连续，不机械套固定级差。偷拍感、监控感和第一人称不自动等于真实，仍须知情同意、隐私保护和事实可读。

表现不自然时，分别检查是否缺“具体场景、人物、动作、变化”的内心视像，或缺明确交流对象；从可停止、默认不发布的短练习开始，每轮只调整一个变量。不得摆拍真实冲突、伪造客户/第三方事件、隐瞒剧情演绎，或为入戏逼迫披露创伤与隐私。

镜头表现力不按夸张、克制、松弛、外貌、音质或抽象“网感”评分。先描述人物状态、动机、关系、动作、声音、场景、光线与内容任务之间的可观察违和；无违和且内容可懂时，不为魅力返工。出镜前补五项镜头外准备：发生了什么、真实感受、为什么现在说/希望推动什么、具体对谁说、本条最终完成什么。真实事实与明确剧情/练习可以使用，虚构家庭、客户、冲突、伤害、疾病和结果不得伪装成真实经历。

为口播设计一项安全、真实的主动作；动作停顿、叠加、走位和道具都必须承担信息、证据、关系、情绪或节奏任务并保持连续，没有任务就删除。声音距离由交流对象与场景决定，不机械跟随相机；先把文案划成重点、铺垫、转折和结果，再设计音量、音调、重音、快慢与停顿。语速、方言、地方口音、语气词和“一股气说完”均不是流量公式。爬楼、压心率、持续发声、呼吸和声带训练不作为通用编导指令；练习须低风险、无痛、可停止，不适时停止并寻求合格专业人员。

### 6. 无稿剪辑与精剪

正式审片前先按知识库的 [[MOC-安先生九特征审片与内容市场]] 做一次内容总监检查：高效性、时效性、任意性、速判性、持续性、原子性、多轨性、刺激性和价值表达。九项是定位缺口的诊断维度，不做加总评分，也不承诺流量。第一时刻要检查整体声画印象，不把“改第一句话”当成全部开头优化；语言、画面、文字与声音需明确主次，互动与转化必须有真实理由。

跨平台重构前分别核对入口的人群构成、打开目的与使用习惯；课程中的固定平台画像只用于提出假设，须用当期官方资料、平台界面和目标用户反馈验证。制作前同时写清预期触达范围、业务价值、承接能力与成本上限，小而准确的触达不因未破圈判失败。遇到“赛道、人设、垂直、流量”等抽象词，先问本次要完成什么决策、观察什么证据和采取什么动作，再选择模型。

先提取唯一中心思想，再把内容拆成背景、判断、动作、证据、条件、反例和结果等信息单元，按目标观众的解码时间重排；先归纳，再合并；删除重复、无效和表现力废镜头；最后重构开篇、正文与结尾。结构粗剪后再处理收声/音量、字幕和语义停顿；停顿必须由前文已建立的期待支撑，节奏来自信息、动作和情绪状态变化，不等于快语速或密集切镜。分屏、画中画和同框可降低跨镜头补全负担，但不得伪造同时性、因果或第三方关系；只在信息、情绪或轻微连续性节点使用景别切换、关键帧和画中画。不得用后期掩盖事实性错误、改变原意，或使用未经授权的第三方素材。

信息效率审片按三层执行：横向逐段检查新增什么以及结构路标是否必要；纵向为同一时点的画面、语言、字幕、现场声和音乐指定一个主信息轨；多轨标记互补、印证、强化或受控张力。任何一轨制造错误时空、人物关系、结果或因果时立即撤回或明确标识。只有结构不易被看见时才用序号、章节、相似句式、时间/空间变化等路标；先修中心承诺、事实链和结构缺口，再单变量调整语速、镜头、字幕、声音或包装。

精剪只服务于信息、情绪和理解：字幕、花字、缩放、画中画、音效、音乐和特效都不得抢戏。

### 7. 成交与平台自检

实体商家内容从产品、店铺、人三个维度中组合至少两个成交理由，避免只做自卖自夸、探店、图文罗列或硬演段子。

平台标签、赛马、铁粉与审核部分是课程模型，不等同于实时官方规则。用户询问当前规则、限流或违规时，先查最新官方资料，再明确区分“课程模型”和“当前事实”。

资料、诊断或体验钩子属于首次交付，必须真实兑现。不得建议 AB 号规避审核、切 IP 伪装真人、伪装素人矩阵、刷假互动、废号引流或批量骚扰私信；使用真实身份、平台允许的承接组件和明确同意。

### 8. 拆片与复盘

拆片先记录账号层和单条视频层的可见事实，再形成竞争性假设，最后提炼可控变量做小规模验证。拆片观察标签可以是知识、过程、观点、故事、产品、其他；它们不等于四类创作脚本。需要表格和完整字段时读取 `references/deconstruction-system.md`。

经营复盘继续追踪 `内容 → 精准关系 → 有效对话 → 线索 → 成交 → 交付反馈`；每周只调整一个主变量，不用播放量代替业务结果。用户只需判断内容是否具备投放前提时，检查唯一业务目标、目标人群、产品承诺和承接路径；需要计划设计、预算、素材投放测试、数据诊断、放量/停投或投放复盘时，路由到 `$douyin-local-promotion-ads`。不得购买表面互动、通过未同意的方式导流，或把固定成本/粉丝数当保证。

扩大自然或付费触达前，检查市场容量、下一触点到达、咨询/成交能力、产品毛利、交付产能、退款与合规；更多流量只会放大当前系统，不能自动把利润同比放大。内容生产按瓶颈在数量与质量之间螺旋切换：生疏时练到稳定合格，合格但供给不足时标准化量产，数量稳定但结果停滞时突破主题/证据/表达/呈现，新质量可复现后再转成新基线。

## 交付标准

默认输出应让执行者可以直接拍摄或剪辑，至少包含：

1. 人群、目标与内容类型；
2. 五维选择及理由；
3. 爆款元素组合及理由；
4. 一句话选题承诺；需要系列化时同时给出主题 IP、稳定项、变化轴和首批候选；
5. 脚本结构或自然流问题链；
6. 追问点与切走条件；
7. 拍摄和镜头提示；
8. 剪辑保留点、删除点与包装点；
9. 内容自检与风险说明。

若用户只要其中一个环节，只交付该环节，但仍检查它与上下游是否一致。

## 质量门槛

- 选题、脚本、提问和剪辑必须服务同一个中心承诺。
- 文案问题先完成层级分诊；抽象判断有必要的可观察证据，具体数字与身份已核验；每段按受众心路推进而非为套模板存在。
- 外部素材先过客观性、有效性、可用性三筛；同行业提炼选题，跨行业迁移呈现，不搬运成品表达。
- 五个维度先定价值，八大元素再造爆点；不要颠倒。
- 八大元素按实际触发的心理机制识别，不按“出现明星、异性、老人或两个对象”等表面词机械分类；主题 IP 的每一期都要独立兑现价值。
- 知识内容检查“信息多、效果快、料够猛、反馈短”；多项建议先给低成本、易理解且不误导的第一步，再说明较高门槛方案与适用条件。
- 观点内容检查写作对象、清晰立场、至少三个论据和具体案例。
- 故事内容检查具体冲突、行动、转机、结果与感悟；阻碍、责任与转机必须有真实依据，艺术加工不得改写因果、时间线、责任或他人意愿。
- 晒过程检查起因钩子、关键步骤、专业细节、困难变化和结果展示；每条还须回答一个真实购买前问题，并如实说明适用条件、成本或限制。
- 成片检查结构完整、中心明确、语言逻辑清楚、画面流畅、爆点前置。
- 表现力复核描述具体违和；五项情境与真实/演绎属性清楚，动作、道具和声音距离各有任务且不伪造事实或造成身体风险。
- 不把爆款公式当作结果保证；用真实数据复盘选题点击、停留、完播、互动和成交。
- 拆片必须分开数据事实、解释假设和复用决策，并保留普通样本、反例和推翻条件。

## 处理课程口径冲突

用户纠正术语或数量时，不要凭印象争辩。读取 `references/full-course-outline.md` 核对当前底稿，并区分：

- 当前导图明确记录的口径；
- 用户口述的其他版本或老师后续版本；
- 为执行方便做出的归纳。

若三者不一致，明确说明差异，不擅自把归纳写成课程原话。

知识库连接可用时，同时读取其“口径决策”；当前 `status: canonical` 的决策优先于离线归纳，但不能改写对应版本的来源原词。
